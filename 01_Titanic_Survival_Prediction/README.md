# Titanic Survival Prediction System

A Machine Learning project predicting passenger survival on the Titanic using a **Random Forest Classifier** and an interactive **Streamlit web application**.

## 🚀 Features
- Predict passenger survival and confidence score
- ColumnTransformer pipeline handling imputation, one-hot encoding, and standard scaling
- Interactive web UI

## 🧠 ML Workflow
```text
Dataset (Titanic) → Imputation → Encoding & Scaling → Random Forest → Model Serialization → Streamlit App
```

## ⚙️ Usage
```bash
streamlit run app.py
```
