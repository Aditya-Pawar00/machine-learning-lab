# Q-Learning Autonomous Agent in Grid World

Tabular Reinforcement Learning implementation solving a 4x4 decision-making grid environment using the Bellman update rule.

## 🚀 Features
- Tabular Q-Learning with Bellman optimality equation
- Epsilon-greedy exploration vs exploitation decay
- Policy extraction and path visualization

## ⚙️ Usage
```bash
streamlit run app.py
```
