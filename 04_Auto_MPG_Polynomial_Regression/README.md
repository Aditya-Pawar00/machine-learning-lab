# Auto MPG Polynomial Regression & Bias-Variance Trade-off

Studies how model complexity influences prediction accuracy and bias-variance balance.

## 🚀 Features
- Evaluates polynomial degrees 1, 2, 3, 5
- Illustrates underfitting (Degree 1) vs balanced curves (Degree 2-3)
- Interactive Streamlit dashboard

## 🧠 ML Workflow
```text
Dataset (Auto MPG) → Standardization → PolynomialFeatures → LinearRegression → Evaluation
```

## ⚙️ Usage
```bash
streamlit run app.py
```
