# Breast Cancer Regularization (Ridge vs Lasso)

Analysis of L1 (Lasso) vs L2 (Ridge) penalties in stabilizing collinear features and producing sparse representations.

## 🚀 Features
- Coefficient shrinkage visualization
- Sparsity and feature selection comparison
- Interactive Streamlit dashboard

## ⚙️ Usage
```bash
streamlit run app.py
```
