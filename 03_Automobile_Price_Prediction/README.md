# Automobile Price Prediction

A regression project predicting automobile market value using multiple vehicle specifications.

## 🚀 Features
- Multiple Linear Regression with Pipeline architecture
- Handles missing markers (`?`) with median/mode imputation
- Interactive Streamlit price estimator

## 🧠 ML Workflow
```text
Auto Dataset → Data Cleaning → Pipeline (Imputer + Scaler + OneHotEncoder) → Linear Regression → Streamlit App
```

## ⚙️ Usage
```bash
streamlit run app.py
```
