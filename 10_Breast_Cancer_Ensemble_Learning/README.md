# Ensemble Learning Comparison

Compares Bagging (Random Forest), Boosting (AdaBoost), and a baseline linear classifier (Logistic Regression).

## 🚀 Features
- Evaluates accuracy, macro precision, recall, and F1-score
- Multi-model consensus voting
- Interactive Streamlit app

## ⚙️ Usage
```bash
streamlit run app.py
```
